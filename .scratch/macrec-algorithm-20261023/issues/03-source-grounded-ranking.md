## RED → GREEN 验收

按 S2 一次实现一个可见行为：可引用的语义差异改变候选名次；一条历史不被当稳定高置信；重复引用不增加支持；缺值退回先验；质量只缩放有依据的调整；必要条件不可补偿；有来源反馈纠错后实际重排。期望值来自独立设计的候选对或手算常量，不由生产函数自己算给自己。

验收条件：

1. 三类分析和管理者在 I1 的具体候选比较中有实际输出，所有 D 候选行齐全；原文缺失不补事实。
2. c/方向/w 的来源有效，显式请求优先，负向表述不会因高评分被强转喜好；q 仍由生产核验获得。
3. 分数在 [0,1]，round12/tie-break 固定；无有效偏好、c=0 或 q=0 的贡献回退行为满足规格。
4. 四消融在干预点切断/替换机制，必要门禁始终保留；下游重新执行或经同字节前缀证明合法复用。
5. 材料/场景变化触发受影响判断和反馈重新处理；新旧推荐及实际调用都有引用记录。
6. 不修改论文公式；“改进”作为待验证候选，不在实现日志预写收益。
