## RED → GREEN 验收

先用公共夹具和外部替身验证未授权拒绝、单次持久发送、未知回执不重发，再验证共享预算和缓存失效；独立评分以手工名次/漏召回/失败/NA 样例对齐旧指标定义。使用既有正确启动包装器，仅运行受影响回归，不把包装器误用导致的旧失败当本轮新回归。

验收条件：

1. 新参数业务核对至多 32 次、开发轮发送上限 6,944；所有失败与未决占用额度，不隐藏重试；未获整份方案确认前真实发送为 0。
2. 24h 与 10GiB 为共享停止线；22h 后不派新模型请求；统计覆盖临时/失败/等待/评价与收口空间。
3. 相同请求可恢复复用，源/权限/时点/场景/决策依赖变更使相应缓存失效；不覆盖旧 compact 输出。
4. 正式 100 用户及原账/研究/论文/接受记录摘要不变；新配置不引用先前授权冒充本轮权限。
5. 全体用户、完整 C 理想增益、共同 D 覆盖、失败/未启动/未决/NA 分列；B0/I1 等真实方法标识保留。
6. 费用与未知 usage 不伪填；新评价不能接触供应商或反向把标签送回运行时。
