## 1 单价与计算口径

M=1,000,000 Token，输入 **¥0.045/M**，输出 **¥0.225/M**。这是用户提供的估算单价，未另行查询供应商价格或余额。输出用量包含其中的 reasoning 子量，不重复相加。

无缓存优惠、额外倍率按1的基础估算为：

`C_base = 输入Token/1e6×0.045 + 输出Token/1e6×0.225`。

| 项目 | 取值/处理 |
| --- | --- |
| 普通输入 | ¥0.045/M |
| 输出（含其中推理） | ¥0.225/M |
| 缓存输入价格 P_cache | 未提供，单列null；估算不给缓存折扣 |
| 额外倍率 κ | 未提供，单列null；基础表按κ=1演算，不能当作已核实无附加倍率 |
| 固定/按次附加费 F | 未提供，单列null；不混入基础Token费用 |
| 失败/未决的usage或扣费 | 未知保持unknown，不当0、不以成功均值补齐 |

缓存单列调整：若缓存命中 Tc Token，`Δ_cache = Tc/1e6×(P_cache−0.045)`。额外倍率和附加费再列为 `C_final = κ×(C_base+Δ_cache)+F`。若给定中转价已经是最终结算价，不再套一次渠道倍率。缓存命中、折扣价、κ或F未确认前只报已知基础估计和未知项。
