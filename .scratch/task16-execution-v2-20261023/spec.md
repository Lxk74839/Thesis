## 1 已确认的运行控制接口

用户已明确要求的公共 seam 是独立 PowerShell 的 Start / Status / Resume、持久进度和不重发未决请求。将这些职责具体命名为 `run-task16.ps1 -Action Status|Start|Resume|Stop|Worker`；`Worker` 是脚本内部启动动作。Python 控制器公开同名 CLI，模型请求通过公开 `Session.invoke(request, send, ...)` 持久化。TDD 仅覆盖这一 S4 控制接口；不将本轮要求扩大为对推荐算法或真实 API 的授权。

Status 是只读入口。Start / Resume 必须绑定完整计划、生产 worker、代码与来源清单及两个审查报告；再由独立 PowerShell 的 `-ConfirmLive` 明确授权。缺任何项返回 not_ready，不读取凭据、不创建 API 意图。未决请求不因 Resume 被重新发送。
