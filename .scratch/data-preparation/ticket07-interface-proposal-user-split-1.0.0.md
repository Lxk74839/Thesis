## 4. 可选引用清单的最小格式

每行只含两字段，例如合成夹具：

```json
{"reference_id":"root-1","user_id":"fixture-user-001"}
{"reference_id":"root-1-scenario-1","user_id":"fixture-user-001"}
{"reference_id":"root-1-scenario-1-repeat-2","user_id":"fixture-user-001"}
```

reference_id是唯一、不透明的引用编号，不据其文字判断场景类型或决定组别。对每行严格查询已有账号组，不能重新哈希场景编号。未知账号、重复引用编号或非法类型要明确失败，不能静默丢弃。增加引用行不改变账号名单、开发／测试人数或独立账号数。
