# 13: 组装共用联合任务并独立验收参考答案

**What to build:** 通过公共数据准备入口把商品、全部评论、SIM 材料和两模块共用根任务组装为联合试制包，提供隔离的输入与独立偏好及证据参考。

**Blocked by:** 08：试制偏好根任务并落实输入与标签隔离；12：确认主要比较、统计方案与样本量依据

**Status:** ready-for-agent

- [ ] 联合包同时包含父商品、全部匹配评论、SIM 批次事件及证据，以及两模块共用的实验根任务，不仅提供评论或偏好任务。
- [ ] 同一根任务在所有方法下使用一致的用户历史、请求、完整候选、基础分数、证据快照、访问范围及预算条件。
- [ ] 真实偏好参考保留在父商品层；SIM 证据资格参考按候选与场景另行判定，不能互相替代或冒充真实供应链标签。
- [ ] 独立参考直接依据原始材料、登记事实和确认协议产生；生产核验器或模型输出不得兼任评价答案。
- [ ] 模型输入与私有评价侧实际隔离，候选排序、标识、材料命名及可见文本不泄露答案；保留无合格候选和不适用情形。
- [ ] 公共入口微型夹具可走通完整联合准备路径，检查对象关联、时间、权限、标签隔离及独立参考；试制通过不能替代全量验收。
