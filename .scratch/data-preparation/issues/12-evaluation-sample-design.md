# 12: 确认主要比较、统计方案与样本量依据

**What to build:** 结合用户流失诊断与已确认场景，提出可公平比较、按用户统计且有充分性依据的联合实验方案，经确认后形成可执行判定规则。

**Blocked by:** 07：报告用户样本流失并确认分组与旧数据复用；11：确认并生成异常场景与无关变化对照

**Status:** ready-for-agent

- [ ] 明确主问题、主比较、主要指标、基础评分方法与版本、候选顺序及共同信息访问条件。
- [ ] 确认预算、重试、计费、时限、失败和发布前检查口径；所有方法在相同根任务和证据快照下比较，不剔除失败以美化结果。
- [ ] 确认排序截点、用户内场景汇总、场景权重、不适用用户和相关性处理，以及用户配对重采样规则；已有论文数值仍需明确批准。
- [ ] 根据所需估计精度或有依据的效应与功效论证所需独立用户数，记录方法、假设及历史和覆盖要求；不能任意填写最小样本量。
- [ ] 如需估计方差或效应，只使用独立开发诊断或可信外部依据，不依据正式测试结果反复修改充分性标准。
- [ ] 提出样本不足时扩大合规来源范围或调整研究主张的备选路径及影响；不得以重复场景增加独立样本。
- [ ] 通过公开可核算的例子验证统计与充分性规则，留存用户明确结论；尚未确认时输出待判定。
