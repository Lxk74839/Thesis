# 03: 获取完整评论并核查关联与时间事实

**What to build:** 通过公共数据准备入口取得完整评论来源，验证评论与父商品的关联字段和时间字段事实，形成可复核的原始来源与字段诊断。

**Blocked by:** 02：获取完整商品元数据并核查字段

**Status:** ready-for-agent

- [ ] 记录评论来源版本、获取信息、字节数、SHA-256 和完整扫描结果；保留所有评分及原始文本。
- [ ] 核实父商品标识与变体标识的含义，统计关联缺失和异常；不得将真实评论关联到 SIM 批次。
- [ ] 通过官方说明和实际样本确认时间字段、单位与时区映射，保留原始时间值及可审计的转换依据。
- [ ] 单独报告损坏、解析失败、缺失字段和异常时间；尚未确认的处理规则不能被隐式应用。
- [ ] 公共入口夹具覆盖文件末尾评论、关联缺失和时间映射；实验场景、预算及所需用户数未确定不阻断本工单。

## 未决前置事项

D2 的实际字段、单位、时区等事实由官方资料与实际记录交叉核实；时间截断和异常记录处理选择留待工单 06。
