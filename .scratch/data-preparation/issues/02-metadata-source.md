# 02: 获取完整商品元数据并核查字段

**What to build:** 通过公共数据准备入口取得完整商品元数据来源，完成完整性检查及字段事实核查，提供可追溯的原始来源和诊断结果。

**Blocked by:** 01：补齐本地 Git 与 Thesis 专属环境

**Status:** claimed

- [ ] 记录官方来源、获取时间、来源标识、下载地址、字节数及 SHA-256；提供可复查的来源完整性依据。
- [ ] 处理完整来源至文件末尾并检查压缩流完整性，不能以文件前缀、固定行数或已有商品清单替代完整来源。
- [ ] 核查实际父商品标识、类别、标题、描述等字段及类型，记录官方说明与实测差异、缺失和解析异常。
- [ ] 保留未经研究筛选的原始数据；诊断产物明确标注为诊断，不冒充正式目录或联合数据包。
- [ ] 微型夹具通过公共入口证明后段商品可被读取、不完整来源得到明确诊断；完整来源另有实际核查记录。
