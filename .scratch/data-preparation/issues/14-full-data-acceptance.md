# 14: 实测完整数据并判定独立用户样本充分性

**What to build:** 对完整真实来源和联合试制包执行独立验收，按预先确认的标准实测独立用户数量及样本充分性，交付可复核的通过、不足或待判定结论。

**Blocked by:** 13：组装共用联合任务并独立验收参考答案

**Status:** ready-for-agent

- [ ] 验证完整来源、正式目录、全部评论提取、清洗计数和对象关联，核对阶段流失及记录守恒。
- [ ] 检查用户分组、历史与目标、背景统计、输入与标签隔离、共用任务及独立参考，不能以微型夹具通过替代真实全量检查。
- [ ] 独立样本以确认口径的不同来源账户统计；同用户历史、候选或重复场景不得增加独立样本数。
- [ ] 报告各主要指标可用用户、不适用用户、历史与商品覆盖及相关性限制，按预先确定规则判定充分性。
- [ ] 证据不足输出待判定，用户数不足输出不足并阻断正式冻结，不能隐藏损失、放宽规则或重复场景后宣布通过。
- [ ] 提供不足原因和推荐补救方案及影响，保留完整诊断、规则版本和独立复核证据。
