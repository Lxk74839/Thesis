# 05: 提取全部匹配评论并诊断清洗影响

**What to build:** 提取所有入选父商品的全部来源评论，展示去重、时间处理及用户资格候选方案造成的样本流失，为规则选择提供诊断依据。

**Blocked by:** 03：获取完整评论并核查关联与时间事实；04：审计商品范围并确认筛选与元数据冲突规则

**Status:** ready-for-agent

- [ ] 完整扫描评论来源并提取全部匹配记录，保留低评分、空文本和零评论入选商品，不仅提取可用于偏好任务的评论。
- [ ] 核对完整来源的匹配数量与提取结果，报告重复、冲突、异常时间、缺失关联及解析失败。
- [ ] 展示候选清洗规则分别及组合造成的商品、评论、独立用户流失，保留规则和计数口径。
- [ ] 将原始提取、候选诊断与正式清洗结果区分；未确认规则不能作为默认正式产出。
- [ ] 通过公共入口验证后段匹配评论、零评论商品及重复与冲突样本的诊断行为。
- [ ] 报告用户历史深度、不同历史商品数及潜在目标数量分布，不据此直接宣称样本充分。

## 未决前置事项

本工单不冻结 D2—D4；候选处理只生成清晰标注的条件诊断。正常或异常场景、评价预算和样本量阈值不构成本工单前置条件。
