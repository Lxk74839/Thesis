# 农产品画像

输入：候选商品目录、验证后的偏好，以及已经取得的库存观察。

输出：B0输出有来源的比较；I1输出每个候选与每项偏好的匹配值m和来源码f。

设计：负责商品和偏好的对应。m取0、0.25、0.5、0.75、1或未知；f区分标题、类别、库存、未知。未知不能当作满足。

下列业务提示须接在00号公共提示词之后，两者合起来才是完整system提示词。B0和I1按实验方法分别选用。

## I1正常产品分析模板

当前源码可生成的 I1 模板；未找到本版此分支的真实发送记录。以下不是一次已完成的模型调用。Schema使用一个明确标为示例的候选和空偏好列，仅展示结构；真实运行会据候选数和偏好数展开。

Compare candidates against validated preferences using source fields. Give every candidate exactly once as {i,m,f}; column order is state.preferences. m is 0,.25,.5,.75,1 or null; f is 0=title,1=crop,2=stock,3=unknown. Title supports observable form/title terms, crop supports crop, stock needs a supported acquired observation. Host expands the exact source field plus preference citations. Semantic equivalence such as rolled oats/oat flakes is allowed. m expresses satisfaction including preference polarity; absence of a mentioned property does not prove a negative preference is satisfied. Zero preferences still requires every candidate row with empty m/f. Unknown never means satisfied.
