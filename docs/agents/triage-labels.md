# Triage Labels

五个规范分流角色与本地工单标签保持同名。

| 技能中的角色 | 本项目标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 需要维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可由智能体实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予实施 |

技能提到某个分流角色时，使用本表对应标签，写入工单的 Status: 行。
