# Thesis

一种基于区块链与多智能体技术的农产品可信推荐方法。

本仓库保存推荐算法、生命周期证据访问与核验、模拟供应链、实验运行与独立评价代码，以及规格、验收记录、100用户CSV展示数据和组会材料。当前快照日期为2026年10月25日。

## 方法与当前进度

系统包含全链路证据管理与多智能体推荐两个模块。六个角色为需求解析、推荐管理、用户画像、农产品画像、生命周期追溯和推荐依据核验。

数据路线采用真实谷物商品与评论，加同商品的模拟供应链。历史评论关联父商品，再关联该商品的SIM批次。SIM材料用于受控实验，不代表真实用户购买过对应模拟批次。

旧版Compact已完成固定100名用户、18场景实验。R、S、M分别指规则画像、单次模型画像和六角色依次分析画像。现有结果尚未证实M总体优于R或S。MACRec基线与改进方法的主对照仍未完成；区块链相关的真实Fabric部署也尚未完成。具体状态以各工单记录为准。

## 目录

- 根目录Python文件：数据清洗、任务构造、证据核验、推荐运行器、模型适配及独立评价。
- `config/`：数据、场景、运行和评价协议配置。
- `tests/`：本地单元测试及协议测试。
- `docs/`：数据来源、项目约定及迁移说明。
- `records/`：固定输入、验收和存储迁移记录。
- `.scratch/`：历史工单、实施合同、诊断脚本与验收证据。
- `sources/`：原始数据来源描述。
- `reports/`：阶段成果、CSV导出、Word汇报、截图和打包材料。

## 运行环境

当前验证环境为Windows与Python 3.13.16，使用项目专属Conda环境。环境描述见 `environment.yml`，原Windows环境锁定记录见 `environment-win-64.lock.txt`。

```powershell
conda env create --prefix .\.conda\envs\Thesis --file environment.yml
conda run -p .\.conda\envs\Thesis python --version
```

项目核心代码使用Python标准库。报告制作工具和MACRec子模块各有独立依赖，不属于核心运行环境。部分实验路径与固定校验仍绑定原工作目录 `D:\Work\Codex\Project\Thesis`；迁移与复现实验前请阅读 `AGENTS.md`、`docs/operations/project-migration-20261019.md` 和相应工单。
